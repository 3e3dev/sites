# 3e3dev Sites

A lightweight portfolio of the public GitHub Pages projects on 3e3dev.

Live: https://3e3dev.github.io/sites/

The published site is plain HTML and CSS, with no client JavaScript, remote fonts, tracking, or runtime dependencies. Images are served by the original project sites; attribution is available at the bottom of the page. Motion respects reduced-motion preferences.

Edit `src/index.html` and `src/style.css`, then run `npm run build` to update `docs/`. Run `npm run dev` for a local preview. GitHub Pages publishes the `docs/` directory on `main`.

The collection was verified against GitHub's Pages configuration on September 6, 2026 (UTC): fern-atlas, helvella-atlas, and tom-sutton. The portfolio itself is intentionally excluded. Add future published projects to the source and rebuild.
